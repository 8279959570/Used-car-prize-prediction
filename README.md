# used_car_prize_prediction
🚗 Used Car Price Prediction System

A machine learning project that predicts the selling price of used cars based on various features such as the model, fuel type, transmission, kilometers driven, and more.

📌 Project Overview

This project aims to help users estimate the approximate price of a used car.
Using machine learning algorithms and real-world car datasets, the model learns how different features affect the resale value of vehicles.

🎯 Objectives

Build a ML model that predicts accurate car prices

Perform Exploratory Data Analysis (EDA)

Preprocess and clean real-world car data

Train and evaluate multiple regression models

Deploy the model (optional using Flask/Streamlit)

🛠 Technologies Used

Python

NumPy

Pandas

Matplotlib / Seaborn

Scikit-Learn

Jupyter Notebook

(Optional) Flask / Streamlit
